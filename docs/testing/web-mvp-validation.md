### Resource observations/warnings

The full uncompressed Web output was 42,532,302 bytes/38 files, including local renderers/fallback artifacts. This is neither initial-download size nor APK size. Two fonts totaled 182,664 bytes (~178 KiB); the full ~17 MB upstream font stayed out of Git. Material icons were reduced to 8612 bytes.

The compiler reported optional CupertinoIcons not bundled. That version used Material icons only and was visually checked; this historical result did not qualify future Cupertino controls. Two newer dependencies were outside pinned SDK constraints and were not upgraded just to suppress notices. Android memory/energy/APK/frame-time were not measured.

### Reproduce

Use PowerShell 7 at the repository root after SDK setup:

```powershell
./tools/check/check.ps1
./tools/build/web.ps1
python -m http.server 7357 --bind 127.0.0.1 --directory src/apps/pay_by_second/build/web
npm install --prefix .local/qa playwright@1.65.0 --no-save --ignore-scripts
node tools/check/browser-smoke.cjs
```

Serve Web in a separate terminal. Edge is the default; PBS_BROWSER_CHANNEL may select an installed Playwright-supported channel. Ordinary app use needs no Node/Playwright/Python.
